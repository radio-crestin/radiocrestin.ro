# radiocrestin.ro

## Dev Server
- Port: **3005** (`npm run dev` runs on http://localhost:3005)

## Stack
- Astro 6 (static output) with React islands (`client:load`)
- TypeScript, SCSS Modules, Zustand
- Hosting: Cloudflare Pages (`wrangler.jsonc`, output `dist/`) — serves directory-format URLs, 308-redirects `/x` to `/x/`
- API: https://api.radiocrestin.ro/api/v1/stations

## Project Structure
- `src/pages/` — Astro pages (thin shells; SEO objects + JSON-LD in frontmatter)
- `src/layouts/BaseLayout.astro` — global head: meta, Open Graph, canonical, Organization/WebSite JSON-LD
- `src/common/components/` — React components (`RadioApp`, `StatisticiApp`, etc. are page islands)
- `src/common/utils/seo.ts` — per-page SEO objects; canonical URLs use trailing slash
- `src/common/models/` — TypeScript interfaces
- `src/common/services/` — API calls (fallback to `src/common/data/fallback-stations.json`)
- `src/common/store/` — Zustand stores
- `public/icons/` — SVG icon components
- `scripts/` — build-time generators (sitemap, llms.txt, station thumbnails)

## SEO conventions
- All internal URLs use the trailing-slash form (`/radio-gosen/`) to match host redirects
- `public/sitemap.xml` and `public/station-thumbnails/` are gitignored build artifacts —
  regenerated by `npm run build` (Cloudflare build command must be `npm run build`, not `astro build`)
- Station subpages (`/recent-songs`, `/reviews`) are modal deep-links that canonicalize
  to the station root and are excluded from the sitemap; `adauga-recenzie` is noindexed
